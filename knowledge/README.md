## Content Guidelines

### 1. regulations/（法規制）

**目的**: 法令に基づく制約条件を定義

**含めるべき内容**:
- 法令名と条文参照
- 人事制度への影響
- 具体的な数値基準（最低賃金、割増率等）
- 更新日（法改正への追従）

**注意**: 法令は改正されるため、定期的な見直しが必要

### 2. case-studies/（参考事例）

**目的**: 実際の制度設計事例を参照用に格納

**含めるべき内容**:
- 企業規模
- 導入した制度の概要
- 成功/失敗のポイント
- 学びと適用可能な知見

---

## Update Protocol

1. 変更がある場合は、変更日と変更者を記録
2. 法規制は四半期ごとに見直し
3. 事例は随時追加

## Quality Checklist

各ドキュメントは以下を満たすこと:

- [ ] 情報源が明記されている
- [ ] 最終更新日が記載されている
- [ ] 具体的な数値・基準が含まれている
- [ ] AIが参照しやすい構造になっている
