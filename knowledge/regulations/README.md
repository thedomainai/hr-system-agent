## Required Content per Document

各法規制ドキュメントには以下を含めること:

1. **法令概要**: 法令の目的と概要
2. **人事制度への影響**: 制度設計時に考慮すべき点
3. **具体的な基準**: 数値、期限、条件等
4. **違反時のリスク**: 違反した場合の罰則等
5. **チェックポイント**: コンプライアンスチェック時の確認項目
6. **参考リンク**: 公式情報源へのリンク
7. **更新履歴**: 法改正への追従記録
